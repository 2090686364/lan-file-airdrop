# 局域网文件空投系统

基于局域网的跨设备文件传输系统，支持手机与电脑、电脑与电脑之间的快速文件共享和剪贴板同步。

## 下载使用（无需安装 Python）

如果你是普通用户，不想折腾环境配置，直接下载打包好的可执行文件即可：

👉 **[下载最新版本](https://github.com/2090686364/lan-file-airdrop/releases)**

1. 在 Releases 页面下载 `lan-file-airdrop.exe`
2. 双击运行，浏览器会自动打开
3. 手机扫码即可开始传输

> 仅限 Windows 系统。macOS / Linux 用户请参考下方「开发者运行」方式。

## 开发者运行

如需从源码运行或二次开发：

```bash
pip install -r requirements.txt
python server.py
```

### 命令行选项

```bash
python server.py --port 9000          # 指定端口
python server.py --host 192.168.1.100 # 指定IP
python server.py --no-browser         # 不自动打开浏览器
```

## 核心特性

- **文件共享** — 拖拽上传、批量传输、文件夹上传，支持断点续传
- **剪贴板秒传** — 电脑复制文字，手机/其他设备即时收到，延迟 < 1秒
- **二维码访问** — 终端显示二维码，手机扫码直达，无需手动输入地址
- **多设备协作** — 一台电脑运行服务端，所有设备浏览器访问即可互通
- **高速传输** — 不限速，千兆局域网可达 85-100 MB/s
- **反向空投** — 电脑端可将文件推送到手机/其他设备下载

## 使用示例

| 场景 | 操作 |
|------|------|
| 手机照片传电脑 | 手机扫码 → 选择照片上传 → 电脑下载 |
| 电脑文件发手机 | 电脑打开网页 → 上传文件 → 手机刷新下载 |
| 跨设备复制粘贴 | 电脑 Ctrl+C → 手机弹窗 → 点击复制 |
| 办公室多机协作 | 主机运行服务端 → 其他电脑浏览器访问 → 共享文件 |

## 常见问题

**Q: 手机扫码后无法访问？**
- 确保手机和电脑在同一 WiFi
- 检查电脑防火墙是否允许 Python 网络访问
- 确认路由器未开启 AP 隔离

**Q: 上传速度很慢？**
- 优先使用 5GHz WiFi 或有线网络
- 靠近路由器，关闭其他占用带宽的应用

**Q: 文件保存在哪里？**
- 共享文件存储在 `send_files/` 目录
- 上传文件存储在 `uploads/` 目录
- 分块临时文件存储在 `chunks/`（自动清理）
